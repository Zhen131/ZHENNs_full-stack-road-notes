## 一、结论

本批只打磨首页底部交易活动区域：保留左侧约三分之一宽的持仓概览，移除独立“最近交易”卡，把右侧约三分之二宽度完整交给“最近 365 天交易活动”。热力图改为 GitHub Contributions 式的一天一格、周一至周日七行、约 53 个自然周列；删除月份、星期和五级文字图例，保留暖灰至深橙五级相对活跃色阶。

有交易日悬停显示准确日期、笔数和资产方向摘要；点击后进入完整交易列表，平滑定位到该日期，并让当天全部交易行柔和闪亮两次。无交易日悬停不显示内容，点击时才用同款 tooltip 显示“当天无交易”，不跳转。

本批不做年份切换、不在首页继续展示最近交易、不修改交易或估值业务逻辑，也不改写 `LedgerData`、`.lftl`、持久化、安全删除或任何金额口径。

## 三、已确认产品合同

### 3.1 首页布局

1280×800 及更宽桌面采用：

```text
┌─────────────────┬──────────────────────────────────────┐
│ 持仓概览，约 1/3 │ 最近 365 天交易活动，约 2/3          │
│ 保持现有内容     │ [          7 × 约 53 日格          ] │
└─────────────────┴──────────────────────────────────────┘
```

- 两卡位于同一行、等高；持仓概览内容和“查看全部持仓”行为不变。
- 交易活动卡标题固定为 `最近 365 天交易活动`，右上固定为 `查看全部交易`。
- `查看全部交易`进入未筛选的完整交易列表，从最新交易开始；不得触发日期定位或展开详情。
- 删除首页独立“最近交易”卡、最近四笔计算和对应首页入口；不在热力图下方补最近三笔。
- 不为未来年份切换保留空白、占位按钮或隐藏接口。
- 1100px 以下沿用首页现有重排原则，两卡上下排列；不牵动中部趋势图、快捷记账和资产分配。

### 3.2 日期网格

- 一格代表一个自然日；严格保留最近 365 个日期，不得为了 52 列删减日期。
- 自然周从周一开始：第一行周一，第七行周日；横向固定约 53 列。
- 最新日期必须位于最右侧自然周列，具体行由当天星期决定；只有周日才可能位于右下角。
- 今天之后的未来位置不生成日格，也不能伪装成“无交易”。
- 每天跨过本地账本日期边界后，最旧日期退出、最新日期进入；继续复用现有 `todayKey` 与账本日期工具，不新增系统时区推断。
- 删除可见月份、星期、年份和“无交易 / 低 / 较低 / 较高 / 最高”文字。
- 无交易的真实过去日期仍保留最浅色日格，全年没有交易时也完整绘制 365 格。

### 3.3 日格视觉

- 保留当前暖灰至深橙的五级颜色，不改成 GitHub 绿色。
- 继续使用最近 365 天内的相对活跃度：0 笔为等级 0；非零日按年度最高日的约 25% / 50% / 75% 边界进入等级 1—4；最高日为等级 4。
- 1280×800 主尺寸目标为约 9—10px 可见方砖、约 2px 间距和轻微圆角。
- 热力网格自身设置最大宽度并在卡片内居中；1440px 及更宽不让日格无限拉长。
- 窄屏始终保留完整约 53 列，按可用宽度自动缩小日格，不启用内部横向滚动、不隐藏热力图、不删除日期。
- 首页活动卡与持仓卡保持等高，热力网格在标题以下的可用区域垂直居中；不得用释放出的空间新增其他业务内容。

### 3.4 Tooltip

有交易日期的触发和内容：

- 鼠标进入有交易日格时显示，离开该日格时关闭。
- 日期使用 ISO 格式，例如 `2026-06-22`。
- 显示 `共 N 笔`、`买入 N 笔`、`卖出 N 笔`。
- 同一资产、同一方向合并，例如 `BTC 买入 ×2`。
- 摘要按组合笔数降序；相同时按资产代码稳定排序，再按买入、卖出排序。
- 最多展示三组；未展示部分按实际隐藏笔数显示 `另有 N 笔交易`。
- 不显示逐笔详情、总成交金额、手续费合计、估值或任何跨币种汇总。

无交易日期的触发和内容：

- 鼠标进入时不显示 tooltip。
- 点击时才在同一日格附近显示同款 tooltip，内容只有 ISO 日期和 `当天无交易`。
- 不跳转交易页；tooltip 在鼠标离开、点击另一个日格、点击卡片外或页面切换时关闭，不设置独立常驻状态栏。

Tooltip 必须浮在热力图之上而不改变卡片高度；靠近左右边缘时自动限制在卡片内部，不得被现有 `overflow` 裁切。首页模式优先使用 React 文本节点渲染自定义 tooltip，不拼接包含资产代码的 HTML 字符串。

### 3.5 点击有交易日后的定位

点击有交易日格后：

1. 关闭首页 tooltip，切换左侧当前页为“交易”。
2. 清除交易页旧的时间、准确日期、资产和类型筛选，显示完整交易列表。
3. 不自动展开任何交易详情，也不进入删除确认。
4. 在最新到最早的完整列表中，找到目标日期最上方的一笔作为滚动锚点。
5. 平滑滚动，使目标日期交易组进入可视区域中部。
6. 目标日期的全部交易主行一起柔和闪亮两次；详情行、筛选栏和整页不闪。
7. 双闪总时长约 0.8 秒：以浅暖色定位底衬承载约 70% 白色柔光，两次脉冲后完全恢复原背景，不残留筛选、展开或高亮状态。

如果系统启用 `prefers-reduced-motion: reduce`，改为立即定位，并用约 1.2 秒静态暖色背景 / 描边表示目标组；不得执行平滑滚动或双闪。

若从首页点击到交易页之间账本事实已经变化，导致目标日期不再有交易，则保留完整列表并显示 `该日期的交易已发生变化，已显示完整交易列表`；不得滚到错误日期或保持永久定位状态。

## 四、实现合同

### 4.1 派生数据

在图表派生层扩展热力日数据，增加非持久化的资产方向分组：

```ts
type TradeHeatmapActivityGroup = {
  assetSymbol: string;
  type: "buy" | "sell";
  count: number;
};

type TradeHeatmapDay = {
  date: string;
  total: number;
  buys: number;
  sells: number;
  level: 0 | 1 | 2 | 3 | 4;
  activityGroups: TradeHeatmapActivityGroup[];
};
```

- `buildTradeHeatmap`在现有日期计数循环内同时按 `assetSymbol + type` 聚合，返回稳定排序后的全部分组；tooltip 只截取前三组。
- 该结构只属于页面派生数据，不得写入 `LedgerData`、IndexedDB、`.lftl`、备份或 repository。
- 继续按交易保存的账本日期键归组；不得把日期转成本地 `Date` 后因设备时区移动历史交易。
- 等级计算函数和五级阈值保持不变。

### 4.2 首页热力图模式

- 将当前含义模糊的 `compact` 行为收敛为明确的首页展示模式；首页模式隐藏月 / 周 / 年标签和可见 `visualMap`，但仍用现有五级 pieces 着色。
- 旧 `ChartsOverview` 调用保持原有完整图表语义；首页样式、tooltip 和点击定位不得误伤其他调用入口。若调整组件 props，使用明确的 variant / 判别联合类型，不用一组互相冲突的可选布尔值。
- 首页模式维护同一套自定义 tooltip 状态：有交易日由 mouseover 触发，无交易日只由 click 触发；非零日 click 调用交易定位，零交易日 click 只显示 tooltip。
- 日格尺寸由热力图可用宽度和固定 53 列计算，并设置桌面最大值；不要靠缩短日期范围或页面级横向滚动解决宽度。
- 删除 `HomeWorkspace` 中的 `getLatestTrades`、最近交易列表及其专用测试；保留“查看全部交易”的清筛选导航能力。

### 4.3 导航意图

扩展交易工作区导航意图，明确区分三个行为：

```ts
{ page: "transactions"; filterDate: string }   // 保留：只显示准确日期
{ page: "transactions"; locateDate: string }   // 新增：完整列表中定位日期
{ page: "transactions"; clearFilters: true }   // 保留：完整列表，从最新开始
```

- 首页热力日格只发送 `locateDate`，不得复用 `filterDate`。
- 交易页现有手动准确日期筛选和未来其他 `filterDate` 调用继续可用。
- 接收 `locateDate` 时先复位全部筛选、详情展开、删除预备和临时反馈，再建立一次性日期定位状态；消费 intent 后不得在普通重渲染中重复滚动或重复闪光。
- 页面离开、账本 epoch 变化或新导航意图到达时清理定位状态和计时器。

### 4.4 交易表定位与动画

- 交易表按日期键识别目标组；滚动锚点是当前降序列表中该日期的第一笔。
- 目标日期的全部主行共享定位样式；详情展开行不参与动画。
- 使用 `scrollIntoView({ behavior: "smooth", block: "center" })`；支持 `scrollend` 时在滚动结束后开始双闪，不支持时使用受控短回退计时，且卸载时清理。
- 动画只改变表现，不改变交易顺序、筛选、选择、详情或删除状态。
- 对减少动态效果使用 `matchMedia` / CSS media 共同守门，自动测试必须能稳定控制两种分支。
