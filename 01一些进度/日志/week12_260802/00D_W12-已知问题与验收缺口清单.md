## 已接受平台限制

纯浏览器单文件模型不能保证：

- 页面或 Chrome 进程死亡后继续执行补偿；
- 文件权限永久丢失后仍能写回并复读旧 C；
- 外部原生程序抢先改写后，网页仍能回滚或提供 OS 级锁；
- 任一 post-close 异常最终都能证明磁盘恢复为旧版本。

仍然有效的合同：

```text
正常成功必须 write → close → readback → 解密 → 完整校验
→ 只有能证明磁盘仍是本事务 candidate 时才允许补偿
→ 无法证明安全结果时 fail closed，停止后续写入并如实提示
```

来源：[Week 11 03B 执行记录](../week11_260727/03B_W11-B历史导入预检与整本原子替换合并执行记录.md)。这些是已接受能力上限，不计入待修缺陷；未来重新讨论桌面端时再决定是否用原生事务能力改变合同。
