## 01：金额、手续费与净盈亏

### 用户结果

页面不再写模糊的“总金额”或“暂不计手续费”。用户能分别看到成交金额、实际手续费、买入总支出或卖出净到账，以及含费成本和净盈亏。

新账本的内置资产计价币种、新交易、手工 / Binance 价格快照和手续费统一为 USDT；美元只保留 `1 USDT ≈ 1 USD` 的近似说明，不接实时汇率。

### 固定通过样例

```text
买入 0.1 BTC：成交金额 6500 USDT，手续费 5 USDT
卖出 0.04 BTC：成交金额 2800 USDT，手续费 3 USDT

含费买入成本 = 6505
卖出移除成本 = 2602
卖出净到账 = 2797
已实现净盈亏 = 195
剩余成本 = 3903
```

本批不得修改账本 schema、FeeRule 或 Agent 代码。全量卖清、零手续费、缺价和 `1 USDT ≈ 1 USD` 披露进入 NNA / NNC 强制矩阵。

## 02：版本 2 与手续费规则完整闭环

### 用户结果

用户新建版本 2 账本，在页面新增例如“OKX + BTC，0.1%”或“OKX + BTC，固定 5 USDT”的规则；录入交易时得到候选手续费，可以改成实际值并确认保存。规则更新不重算旧交易。

### 批次闭包

`02` 同时覆盖：

- v2 模型、Validator、资源限制、加密文件 metadata 和 current / previous；
- 新建、打开、重连、clear、版本 2 明文备份、预检和整本恢复；
- 旧 `.lftl`、旧备份和旧 IndexedDB 整账的明确拒绝与入口退役；
- 可选 Trade 平台、固定费、百分比、平台 + 资产匹配和规则版本；
- 规则管理页面、交易候选、用户实际值覆盖、保存和复读；
- 正式回归、失败注入和真实 Chrome 虚构文件验收。

本批按一次 [GPT-5.6 Sol](https://developers.openai.com/api/docs/models/gpt-5.6-sol) 高强度任务设计。若无法完整闭包，NNB / NND 必须如实写未完成、FAIL 或 BLOCKED，不得把遗漏移入 03。

## 03：本机 AI 连接与单 Agent baseline

### 用户结果

用户通过一个统一入口检查网页、Python、Ollama 和 `qwen3:8b`。环境正常时，网页提交一句中文并得到候选；环境缺失时获得明确提示，账本不变。

### 边界

- 当前本机未检测到 Ollama，03 必须先验证安装状态、模型存在和实际响应时间。
- 统一入口不自动下载、安装或静默换模型。
- Python 核心同时供 localhost 服务和未来 Notebook 调用。
- 单 Agent 输出允许缺字段，只是 baseline，不得写 `.lftl` 或 IndexedDB。

## 04：提取 Agent 与审核 Agent

### 用户结果

提取 Agent 先形成候选，审核 Agent 对照用户原文指出缺失、矛盾和猜测；最多返回提取 Agent 修正两轮。仍无法确定时停止内部循环，把问题交给用户。

两个 Agent 必须使用不同 system instruction，但可以共享固定 `qwen3:8b`。本批只产候选，不制作追问页面、不使用手续费规则、不写账。

## 05：歧义追问与逐笔预览

### 用户结果

```text
“成交金额 6000，另外手续费 5”
→ 成交金额 6000，手续费 5

“总共支出 6000，包含手续费 5”
→ 成交金额 5995，手续费 5

“花了 6000，手续费 5”
→ 先追问是否包含手续费，未回答时零写入
```

用户逐笔看到原话、亲自给出的澄清、平台、资产、数量、成交价、成交金额、手续费来源、总支出或净到账。用户可以修改候选，但本批没有任何写 C 按钮或生产写入权限。

## 06：逐笔确认与整批一次写入

### 用户结果

每笔交易确认后，网页对整批候选和完整历史时间线做确定性预检；全部通过才执行一次保存，随后 close、readback、解密、Validator 和页面核对。任一不完整、非法、模型超时、账本 revision 变化、重复点击或保存失败均整批零写入。

本批只使用专门新建的虚构版本 2 Demo C。`02D BLOCKED` 继续保留，不得借 Demo 宣布真实个人数据可用。

## 07：信息隔离与公平评估

### 用户结果

- 固定题目和正确答案；
- 同一模型、相同输入合同和公平参数；
- 对比单 Agent 与双 Agent 的字段正确率、整笔正确率、应追问识别率、非法静默写入次数和响应时间；
- 同一 Python 核心整理成无执行输出的课程 Notebook；
- 复验 `.lftl`、版本 2 备份和重开结果不含 Agent 对话、推理、置信度、Prompt、原始响应或实验指标。

本批不新增产品功能，不把课程结果冒充比赛或真实使用证据。
